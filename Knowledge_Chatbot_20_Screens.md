# Knowledge Chatbot (RAG MVP) - UI Mockup Documentation

## Overview
The Knowledge Chatbot is an AI-powered assistant that enables users to search, retrieve, and interact with organizational knowledge using a Retrieval-Augmented Generation (RAG) architecture.
